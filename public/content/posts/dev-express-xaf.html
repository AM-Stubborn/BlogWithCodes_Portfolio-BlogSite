Roadmap for XAF learning

🔹 Phase 1: Foundation (Basics of XAF)

  • What is XAF?

    • Understand the idea of Model-Driven Development (you define business objects, UI and APIs get generated).

    • Learn the architecture: Application > Modules > BO (Business Objects) > Controllers.

  • XPO & EF Core ORM

    • XAF can use XPO (DevExpress ORM) or Entity Framework Core.

    • Learn how to choose one (XPO is older and more integrated; EF is standard).

  • XAF Application Types

    • WinForms

    • Blazor (recommended, modern choice)

    • ASP.NET WebForms (legacy, less used today)

  • XAF Solution Structure

    • MySolution.Module (business logic, entities, controllers)

    • MySolution.Win (UI for WinForms)

    • MySolution.Blazor (UI for Blazor)

    • MySolution.Module.Blazor/Win (platform-specific tweaks)

🔹 Phase 2: Data Layer & Business Objects

  • Business Objects

    • Persistent classes (XPObject, BaseObject, XPLiteObject)

    • Attributes ([Key], [Association], [Aggregated], [Persistent], etc.)

  • Relationships

    • One-to-many, many-to-many

    • Aggregation vs Association

  • Validation Rules

    • Attribute-based validation

    • Rule sets in the model

🔹 Phase 3: UI & Model Layer

  • Application Model

    • Model Editor (central config for UI, security, navigation, etc.)

    • Difference between Model.Designed and Model.User

  • Views

    • List Views (grids)

    • Detail Views (forms)

    • Dashboards

  • Layouts

    • Customizing UI layouts in Designer

  • Controllers & Actions

    • ViewController vs WindowController

    • SimpleAction, PopupAction, ParametrizedAction

    • Event hooks (OnActivated, OnDeactivated, OnViewControlsCreated)

🔹 Phase 4: Security & Authentication

  • Security System

    • Authentication (Username/Password, OAuth, Windows)

    • Permissions

    • Roles & Users

    • Object-level & member-level security

  • Multi-Tenancy

    • If your project needs per-client data separation.

🔹 Phase 5: Advanced Features

  • State Machines

    • Workflow/state management for entities

  • Reports & Dashboards

    • Built-in report designer

    • DevExpress Dashboards integration

  • Localization

    • Multi-language support via model editor

  • Auditing & Logging

    • Object change history

    • Audit trail module

  • File Attachments

    • FileData, FileSystemData objects

🔹 Phase 6: Deployment & Extensibility

  • Hosting

    • IIS / Kestrel for Blazor

    • Desktop installer for WinForms

  • Extending XAF

    • Custom modules

    • Reusable controllers

    • Integration with external APIs

  • Performance Tuning

    • Large dataset handling

    • Optimizing XPO/EF queries
