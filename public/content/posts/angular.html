REST PARAMETER

WHAT IS LAC in NORMAL PARAMETER

Consider the following example of simple function with normal parameter

function sum(a,b)

{

console.log("a+b =", a+b)

}

sum(10,20);

Above function is fine with the normal requirement of the user but what if the user ask to sum more than 10 number later in future?

What will you do?

Will you write a function again for adding 10 numbers? That won’t be good practice and not the best way to resolve this problem

In this situation we use REST Parameter

What is REST Parameter

· A function can be called with any number of arguments with use of REST parameter

· How to define Rest parameter? => with “…variable_name”

Example

function show (...a)

{

console.log("all parameters",a)

}

show(10,20);

Output

Addition of multiple number

function fun(...input){

let sum = 0;

for(let i of input){

sum+=i;

}

return sum;

}

console.log(fun(1,2)); //3

console.log(fun(1,2,3)); //6

console.log(fun(1,2,3,4,5)); //15

Output

Important points

· Rest parameter must be used at the last of all parameter

Output

· If we put rest before other parameter then it will generate error

Arrow Function

What is Arrow Function

· An arrow function expression is a syntactically compact alternative to a regular function expression

· Arrow function was introduced in ES6

· Arrow function reduce the size of the code and easy to use once you get hang of it

Syntax

(parameter1,parameter2, …)=>{

Statement----------------1

Statement----------------2

….

}

Above will be equivalent to below function:

function function_name(parameter1,parameter2, …){

Statement----------------1

Statement----------------2

….

}

Important points of arrow function

· If function body is single statement than we can avoid curly brackets “{}”

Example

()=>console.log("Only one statement in the function");

Equivalent to

console.log("Only one statement in the function")

};

Equivalent to

Function function_name()=>{

console.log("Only one statement in the function")

};

· If function has only one parameter then we can avoid/omit the parenthesis

Example

a=>console.log("a",a)

Equivalent to

(a)=>{

console.log("a",a)

};

Equivalent to

Function function_name(a)=>{

console.log("a",a)

};

· Arrow function has an implicit return

Services

What is services

Angular services are singleton objects that get instantiated only once during the lifetime of an application. They contain methods that maintain data throughout the life of an application, i.e. data does not get refreshed and is available all the time. The main objective of a service is to organize and share business logic, models, or data and functions with different components of an Angular application.

Observables provide support for passing messages between parts of your application. They are used frequently in Angular and are the recommended technique for event handling, asynchronous programming, and handling multiple values.

Observables are declarative—that is, you define a function for publishing values, but it is not executed until a consumer subscribes to it. The subscribed consumer then receives notifications until the function completes, or until they unsubscribe.
