Question-1: What is Observable?

Answer: Observable is a function that will convert the ordinary stream of data into an observable stream of data.

Observable will only emit the value to the objects which are subscribed to observable.

Observable allows you to handle both asynchronously and synchronous code

*********************

Question-2: What is Promise?

Answer: Promise is a function that will allow the execution of a piece of code asynchronously.

*********************

Question-3: What is difference between Observable and Promise?

Answer: Differences are as following:

Observable is Lazy and Promise is eager mean Promise will execute irrespective of then and catch statements whereas Observable will not start until any object is subscribed to it.

Promise execute code asynchronously whereas Observable can be both asynchronous as well as synchronous (That depends on the definition of the Observable)

Promise can emit only a single value and once a value is being emitted then the working of promise is complete, which means promise will only emit a single value whereas Observable can emit n number of the value to tits subscriber.

We cannot cancel the promise functionality once assigned where as we can cancel the subscription to the observable using the unsubscribe method.
