How to Create BehaviorSubject (Observable in Service)

First create object of BehaviourSubject

private IsSideMenuCollapsed = new BehaviorSubject(false);


Now add the observable to the created object of BehaviourSubject

IsMenuCollapsed = this.IsSideMenuCollapsed.asObservable();

Add a method responsible to apply change to the BehaviorSubject object

SideMenuStatus(status: boolean) {
this.IsSideMenuCollapsed.next(status)
}

Now, your observable is ready to use. Subscribe to observable to use it

Note: if you are using observable in a component, use ngOnDestroy() lifecycle hook to unsubscribe the observable

Example:

iscollapsed: boolean = false;
Menusubscription: Subscription;
ngOnInit() {
this.MenuSubscribe();
}

MenuSubscribe() {
this.Menusubscription = this.commonService.IsMenuCollapsed.subscribe((isClosed) => {

if (isClosed == true) {
setTimeout(() => {
this.iscollapsed = true;
this.reset();
}, 1000);
}
});
}
ngOnDestroy() {
this.Menusubscription.unsubscribe();
