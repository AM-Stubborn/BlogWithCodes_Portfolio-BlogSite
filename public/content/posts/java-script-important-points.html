  • Common utility Class
We can create our own utility class so that we don't have too write our code repeatedly, utility class will provide you one place where you can write you common function and call them whenever you need them.

To create utility class in your application create a .js file anywhere inn your folder structure where you are comfortable. Now inside the .js file you have created write all the function you needed.
and in the end of your code export the new object of the class which you want to us. Please see the example below for more clarification.


class MyUtilityClass{
function IsNull(value, CheckEmptyString = true, replaceValue = null) {
if (value != null && value != undefined) {
if (CheckEmptyString == true) {
return value != '' ? value : null;
}
return value;
}
else {
return replaceValue;
}
}
}
export default new MyUtilityClass();
