Animation properties

  • animation-name: name of the animation that is passed to the keyframes
  • animation-duration: Duration of animation
  • animation-delay: delay before animation starts
  • animation-fill-mode: CSS after completion of animation
    • backward: default animation fill mode, in which the object will acquire the initial CSS property that it had before animation. Or you can say it will move back to its initial state.
    • forward: The object will acquire the final state CSS property that it had after the animation completes.
  • animation-iteration-count: number of times animation should run. If set the value to infinite then the animation will run unlimited times
  • animation-timing-function: This property describes how the animation motion will perform.
    • ease
    • ease-out
    • linear
    • cubic bezier: You can customize your motion graph. you can create cubic bezier from cubicbezier.com
  • animation-direction: the direction of motion, if the iteration count s greater than 1
