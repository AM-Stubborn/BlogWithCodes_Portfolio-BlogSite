What is Array

An array is collection of element stored in continuous memory. Here element could be anything, it could be a collection of integer ,string and objects.

There are some important points which we keep in mind while we deal with array as following:

  • In some languages, Array store homogenous element, here homogenous element means array will store only one type of element. And type of element can be define will declaring the array.
  • Array element will be stored in continues memory in main memory.
  • Array element can be access with array index, indexing will start from 0 to size_of_array-1. Where 0th index with contain first element and last element will be stored at size_of_array-1 index
    • so, we can get the value of any element in array using index such as to get 10th element: array[10-1]
  • Note, in some languages, size of array will be fixed and user ne to declare the size of array at the time of array creation.
Interesting Point: array index start with zero not with one. There is a very interesting reason behind it.

if we are declaring a array as :
int[] arrayOfNumbers = new int[] { 1, 2, 3, 4, 5 };'

In above line I created an array of integer with 5 element inside it. So if I have to access element 1 than we can access by, arrayOfNumbers [0] because we know 1st element will be store at 0th Index.

And have you think how our complier read arrayOfNumbers [0], How come it knows we are accessing first element of array ?

In behind the scene, or complier will reserve the continuous space in memory when ever we create an array, and name of the array will hold the first address of the memory space.

So, In our case suppose in behind the scene in our memory, we got 5 continuous memory space as 1005,1006,1007,1008,1009 so first elements will be store something like as following:

1005 store 1
1006 store 2
1007 store 3
1008 store 4
1009 store 5

and first address will be store in name of array, so arrayOfNumbers = 1005

So, compiler will understand arrayOfNumbers [0] as return the value at 1005+0 address = 1
and arrayOfNumbers [1] as return the value at 1005+1=1006 address = 2

As you can see if we start indexing with zero, it will make job easier for our compiler to calculate the address, but if we make it 1 than each time we need to access any element, we need to make our compiler do the unnecessary calculation.

(these are take just as reference in real case this could be depend on machine to machine)
