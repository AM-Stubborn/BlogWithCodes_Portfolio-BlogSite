Authorize.Net Payment Gateway

Authorize.net use to accept electronic and credit card payments in person, online or over the phone.

Important point about authorize.net

· There are two type of account

o Sandbox account: Sandbox account is developer account and developer can use a sandbox account to develop and simulate the application functionality as per the actual/Live authorize.net account.

§ A sandbox account provides all the functionality that is in actual/Live account but there is no actual money deduction.

§ Login to sandbox account at https://sandbox.authorize.net/

o Live account: account from which money transaction take place

§ Only switch from sandbox account to Live account once development is done and payment functionality is stable.

§ Login to live account at https://account.authorize.net/

· To Consume authorize.net API we must have Transaction Key and API LoginId

· We can have generate Transaction Key multiple time but API LoginId never change’s

How to Create an account in authorize.net

· Visit ULR https://developer.authorize.net/hello_world/sandbox.html

· Fill all the required details

· After submitting all the detail, you will redirected to the page where you will be provided API Login Id , Transaction Key, KEY. Make sure to save it properly because these credentials are important to consume authorize.net API.

· Now login to your account at https://sandbox.authorize.net/

· Once you enter you credential, authorize.net will verify by sending a pin to registered email

· Enter PIN and Password and click on verify PIN button

Now you are successfully login to the sandbox account

How to Change Transaction Key

· Login to authorize.net account

· Got to Account

· Under Security Settings è General security setting è click on API Credentials & Keys

· API Credentials & Keys page will be opened and now our aggenda here is to create new transaction key. So, selecte New transaction Key radio button and submit and we can also disable old transaction key by selecting option Disable Old Transaction Key Immediately

· (Note : if don’t select Disable Old Transaction Key Immediately option than old transaction key will be automatically expire in 24 hours)

· To finally get the new transaction key, authorize.net will ask for pin verification that will be sent to the registered email id. So click on Request PIN button and enter the received pin over your email.

· Once the verification is done new transaction key will be generated and displayed over the screen as shown in below screenshot. Please this key for development purpose.

All About Authorize.net Transaction

· Transaction is a process where authorize.net will deducted/ charge a credit card against the provided amount.

· In Authorize.net all recent transaction will be consider as unsettled transaction and authorize.net settle a unsettle transaction with in 24 hrs.

Unsettled transaction

When a credit card is charge against a provided amount in athourize.net than that transaction will be show under unsettle transaction and authorize.net settle a unsettle transaction with in 24 hrs.

Please Follow below step to view unsettle transaction

· Login to the authorize.net

· In Home Page, è Left menu è TRANSACTION SEARCH è Unsettled Transactions

· Unsettle Transaction Page will be opened and you can see all the unsettle transaction there and you can also filter the list.

Settled transaction

Once the unsettle transaction is settle by authorize.net than it will be called as settle transaction.

Please Follow below step to view settle transaction

· Login to the authorize.net

· In Home Page, è Left menu è TRANSACTION SEARCH è Search for a Transactions

· Search for a Transaction will be opened

· Now We have to select settlement date between which we want to see the transaction and then click on submit.

· All the transaction between entered date will be displayed.

Utility Payment Class

· To centralize the payment functionality throughout the application we have created the common utility class in CommonCore dll.

· Payment function class is a static class so we can directly call the class without object creation

· AuthorizePayment is the static method inside this payment function class which accept one argument as AuthorizePaymentModel class object which ask for only important information that require to establish connection with authorize.net

· AuthorizePayment return PaymentResponse object when the method is call which return all the necessity information once the payment is done such as customerId , transactionId and responseCode etc.

· AuthorizePayment return PaymentResponse object.ResponseCode ==200 then transaction is successful else transaction is unsuccessful.

· If transaction is successful the API will return transaction Key, customerProfileId, customerpaymentId.

· If transaction failed dune to any reason than error message is returned in the paymentResponse object property ResponseCode.

· AuthorizePayment can handle both onetime transaction and subscription.

· If argument object AuthorizePaymentModel property IntervalLength!=0 than it is consider as subscription/ ARB else it is treated as one time transaction.

· Only Onetime transaction will return transactionId, if it is subscription/ARB then it will retrun subscriptionId.
