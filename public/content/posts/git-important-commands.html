How to match you current branch with existing other branch

  • completely clone with other branch

If you want you current branch to be sync with other branch, than please follow below step, but please keep in mind that if you follow below step than all the existing new changes will be removed by the git in you selected branch and git will make the exact copy of the branch you you are trying to copy

git checkout <your_branch_name>

 # replace with repository name from which you want to copy 
git reset --hard master
# force push the branch
git push -f   
or
git push origin <your_branch_name> --force


git push origin --delete <your_branch_name>
