Introduction to Nuget Package

Nuget Package is the place where developer can upload there assembly (dll) and other users/organization can consume that assembly. Nuget Package also provide version vise copy to your dll and also provide proper documentation which can help other user to know more about your code and how to apply that.


How to upload package over Nuget Package

  • Create our own Class library
    • create library and add all the basic detail such as author name, organization etc.
    • Once you are done with your code, Build and than Pack your project.
    • Pack will generate a .nupkg file in you bin folder and you can also see the file location in your console.
  • Create you account in https://www.nuget.org/ with outlook account.
  • Once you have account in Nuget.org now upload the .nupkg file generated in your bin folder to the nuget.org Upload page
  • After Uploading Package, nuget will let you know some of the suggestion to improve your package listing.
  • After all the above process, Nuget start the process to list you package over nuget package manager. Process will take 10 -25 min to list your package.
  • Once the package is listed you can use the package now.
