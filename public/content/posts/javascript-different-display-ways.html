Confirm:

confirm will almost same as the alert but confirm we present the user with two choices with ok and cancel and return the user choice

if User selects OK then confirm function will return true and if user selects cancel the confirm function will return false

Syntax: confirm(message)

prompt:

prompt is again almost same as the alert but instead of showing user only message, prompt will present input box in alert pop-up and ask the user for input, and function will return what ever the user enter in input box.

Syntax: prompt(message,default )
