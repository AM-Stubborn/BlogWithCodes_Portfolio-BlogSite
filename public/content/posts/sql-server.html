1) Topic: Comma Separated String

Problem: When you need comma seprated string as an output from a column of a select query.

Solution 1: Assume You need comma separated countries name as output. Country data is in Application.Countries Table inside CountryName column. So Please refer below Query as solution to above problem.

Select CountryName from Application.Countries

Declare @val Varchar(MAX);

Select @val = COALESCE(@val + ', ' + CountryName, CountryName)

From Application.Countries Select @val;

Problem: Different way to create Temp table in sql server

Solution 1: The SELECT INTO approach:
SELECT column_1, column_2, column_3,...  
INTO #name_of_temp_table
FROM table_name
WHERE condition

Solution 2: The CREATE TABLE approach:
CREATE TABLE #name_of_temp_table (
	column_1 datatype,
	column_2 datatype,
	column_3 datatype,
        .
        .
        
	column_n datatype
)
Note that once you created the table under the second approach, you’ll need to insert the records into the table using an INSERT INTO query
