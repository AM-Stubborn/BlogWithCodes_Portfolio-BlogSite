C# Introduction

  • C# is a simple, modern, general-purpose, object-oriented programming language
  • Developed by Microsoft team led by Anders Hejlsberg.

Note: C# was developed at time when Anders Hejlsberg and his team was working on development of DotNet framework.

  • C# is the most practiced language on DotNet framework.

How C# is different from C

  1. C is doesn't based on the oops concept where as C# is truly based on oops(Object oriented programming language) means C# strictly follow oops concepts i.e encapsulation, abstraction etc
  2. C have partial implementation of data structure where as in C# data structure is implemented completely.

How C# is different from C++

  1. C++ follows oops concept partially where as C# strictly follows oops concept strictly.
  2. In C# additionally some concept are added like,
    • Delegates are introduced
    • Events
    • etc
