JWT Token

JWT token stand for JSON web token, and it is used to authenticate the incoming API request and allow trnsmition of json data.

Configure JWT into project

To implement JWT authentication into the porject please follow the belwo step:
  • Install the Microsoft.AspNetCore.Authentication.JwtBearer
  • In program.cs file add new authentication service as shown below
    • Points to be noted while adding authentication service
    • schema can we added as default as shown.
    • with authentcation we will use bearer authentication and add TokenValidationParameters object as
      • Issuer: If ValidateIssuer set true than we need to specify Issuer detail while creating the token and If ValidateIssuer set as false, than no need to specify Issuer detail
      • Audience: Audience represent the recipients that are authorized to access the content.
      • Expiry Time: This indicate till what time the token will be valid and onc the time is up, token will not work for authentication.
      • SignatureKey: This is key important part of JWT as it will be responsible for encrpting the token data, so make sure what ever key you are using while configuring the the ValidationParamter object should be same as the token that you will generate.

  • Once the authentication is added to the service than use the authication in the middleware.
