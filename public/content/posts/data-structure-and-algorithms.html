What is Data Structure

Data structure are like a container which store the data in it within main memory, and we using data structure so that we can effectively store, retrieve and manage our main memory to get the most effective efficacy. Following are some important points about data structures which we need to keep in mind:

1) Data structure define/ describe the shape of the data you are storing inside them.

2) Data structures are the key ingredients for a efficient algorithm.

3) Some of the example of data structures are array, stack, queue, Linked-list, Binary search tree etc.

4) For each data structure, there are some set of rule to store ad retrieve the data from them.


What is Algorithms

An algorithm is the set of instruction to solve a particular problem. By following the step by step instruction from an algorithm one should be able to solve the problem for which algorithm is designed.

Lets understand this with an example, Suppose you want to make coffee, now making coffee is a problem if you are making coffee for first time. So how will you solve this problem. You want a step by step guidance to make coffee. And we actually call that step step guidance as an algorithm for the problem of making coffee. Lets assume you called two persons who know how to make coffee and ask for the process of making coffee. and apparently both of them has different ways to make coffee.

So, by this we can say that, to solve a single problem there could be n number of algorithms.

Keep in mind, if problem is related to IT we can design/ write our algorithms in any understandable language, form or diagram but while implementing that algorithm we need to write it in computer language so that our system can understood that and produce are desired output.
