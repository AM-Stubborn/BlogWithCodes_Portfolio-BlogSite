Singleton Design Pattern

Singleton design pattern while our program to create only single object of Singleton class. with use of Singleton class we can restrict our program to create more than one object of the Singleton class.

How to Implement Singleton design pattern.

To implement singleto design pattern there are certain Key point we need to remember as following:
  • First and most important thing that required, the constructor of the call should be private and parameter less that we restrict the object creation from outside the class.
  • We will create the public static variable that will hold the object of the class.
  • We will create the public static Method that we allow user to create the object of the class if public static variable declared is null else it will create the new object.
  • Lastly we will make the class sealed to insure that no class can inherit data member of the class
