# AI vs Machine Learning vs Deep Learning

Artificial Intelligence (AI), Machine Learning (ML), and Deep Learning (DL) are related — but they are not interchangeable.

## The short map

- **AI** — the broad goal: machines that perform tasks that usually need human intelligence
- **ML** — a subset of AI where systems learn patterns from data instead of only hard-coded rules
- **Deep Learning** — a subset of ML using multi-layer neural networks for complex signals like images, speech, and language

## When to use which term

| You are talking about… | Prefer |
| --- | --- |
| Product capability / agents / copilots | AI |
| Tabular models, classical training loops | ML |
| Neural nets, transformers, vision models | Deep Learning |

## Why the distinction matters

Using precise language helps in interviews, design docs, and stakeholder updates. It also clarifies hiring: an ML engineer optimizing model accuracy is not always the same role as an AI engineer shipping RAG features into a product.
