Multipart/Formdata : will allow us to transfer data over API in chunks and chance reduce the load of the server request to send data in one go

Base64 will first convert the file into the ASCII string which will increase the client machine effort for conversion from one type to the ASCII string and second when we send data In base64 encode then we need to send data in simple post request which we force our server request to push on server in one go, which can increase server load

so if the file size is small(is less than 1MB) then we can think of sending file in BASE64 encode else it is preferable to send large data in multipart/Formdata.
